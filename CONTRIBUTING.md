# Contribution Guidelines

Thanks for helping grow the list. Please make sure your pull request follows these rules.

- Add one link per pull request, and say in the PR description why it belongs on the list.
- Put the link in the section that fits it best. If no section fits, propose a new one in the PR.
- Use this format, and end the description with a period:

  ```markdown
  - [owner/repo](https://github.com/owner/repo) - Short description ending with a period.
  ```

- Keep descriptions short and neutral. Leave out marketing words like "best", "ultimate" or "revolutionary".
- Only add projects that are public, have a README, and relate clearly to the Elephant-Goldfish pattern.
- Empty forks, mirrors and repos with no README won't be accepted.
- Check your spelling and grammar, and remove trailing whitespace.

If a listed project is archived, abandoned or no longer works, open an issue or a PR to remove it.
